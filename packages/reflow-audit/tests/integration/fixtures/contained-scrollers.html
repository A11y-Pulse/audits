Installing the command line tool

Run the installer, then confirm the version. Long commands scroll inside their own box so the page itself never scrolls sideways.

curl --proto '=https' --tlsv1.2 -sSf https://downloads.example.com/install.sh | sh -s -- --channel stable --prefix /usr/local
